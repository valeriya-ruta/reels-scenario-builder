# OpenRouter migration — request-contract equivalence (BEFORE vs AFTER)

> Generated by `scripts/proof/openrouter-equivalence.mjs` from two captures of the
> **real generation code**: `before-groq-gemini.json` (checkout `e156f25`, the
> pre-migration Groq/Gemini code) and `after-openrouter.json` (this branch). Both
> were produced by `scripts/proof/openrouter-capture.mjs` running one fixed
> braindump through each generator with `fetch` intercepted — the exact outbound
> request is recorded, no API key and no live model call.

**Why this is the right proof.** Text generation runs at temperature 0.45–0.85, so
two live calls are never byte-identical even on the same model — "identical output"
is not physically meaningful above temperature 0. What *is* provable, and what
equivalence actually rests on, is that the app sends the **same model, the same
prompt, the same temperature, and the same max_tokens** — only the pipe changed. The
live half (actual generations) is reproducible with keys via
`scripts/proof/openrouter-live-braindump.mjs`.

## Verdict

**PASS** — every generator sends a byte-identical prompt, temperature, max_tokens and JSON-mode request before and after. The only differences are transport: endpoint, auth, and the model *slug* (which maps to the same underlying model).

Model-slug mapping is 1:1 to the same underlying model: Groq
`llama-3.3-70b-versatile` **is** `meta-llama/llama-3.3-70b-instruct`, and
`gemini-2.5-flash` is `google/gemini-2.5-flash`. Each is pinned to the provider it
ran on before (`groq`, `google-ai-studio`) so inference stays on the same backend.

## Carousel + Whisper

- **Carousel** (`app/api/carousel/rant-to-slides/route.ts`) builds its prompt inside
  the authenticated route, so its request is not captured here; the git diff of that
  file for this change shows only the transport lines moved (model→slug, fetch→
  `openRouterChatJSON`, `max_tokens: 3000` preserved as `maxTokens: 3000`) — the
  system prompt and `temperature: 0.7` are untouched. See
  `git diff e156f25 HEAD -- app/api/carousel/rant-to-slides/route.ts`.
- **Whisper** is speech-to-text (no prompt) at `temperature: 0`. Same model
  (`whisper-large-v3-turbo`), same `verbose_json` params; endpoint moves to
  OpenRouter's OpenAI-compatible `/audio/transcriptions`. Being temperature 0 on the
  same model + provider, its output is the one path that *is* expected byte-identical.
